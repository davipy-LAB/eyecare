Privacy Policy for EyeCare Extension Last updated: June 5, 2026 EyeCare Extension is a visual accessibility and comfort tool designed to help users customize their web browsing experience through visual filters, dynamic contrast, comfort mode, scheduled eye break reminders, and optional preference synchronization with the EyeCare web platform. This Privacy Policy explains what information EyeCare Extension collects, how it is used, and how users can control their data. 1. Information We Collect EyeCare Extension may collect or store the following types of information: a) Account information If you choose to create an EyeCare account and log in through the extension, we may process: - Email address - Username - User ID - Account plan/status - Authentication token used to keep you signed in This information is used only to provide login and preference synchronization between the EyeCare website and the EyeCare Extension. b) Authentication information When you log in, your email and password are sent securely to the EyeCare backend for authentication. EyeCare does not store your raw password in the extension. Authentication tokens may be stored locally in the browser so the extension can keep you signed in and synchronize your preferences. c) Visual accessibility preferences EyeCare may store and synchronize your visual accessibility settings, including: - Selected language - Selected visual filter - Color blindness preference - Color blindness filter type, such as Protanopia, Deuteranopia, or Tritanopia - Dynamic contrast setting - Comfort mode setting - Scheduled pause reminder setting These settings are used only to provide and synchronize the accessibility features selected by the user. 2. Information We Do Not Collect EyeCare Extension does not collect, store, sell, or transmit: - Web browsing history - Website content - Text, images, videos, or links from pages you visit - Personal communications - Financial or payment information - Precise location data - Keystrokes - Mouse movement - Advertising identifiers The extension applies visual effects locally on web pages. It does not read or upload the content of those pages. 3. How We Use Information EyeCare uses collected or stored information only to provide the extension’s core features: - Saving user preferences locally - Applying visual filters and contrast settings - Enabling comfort mode - Sending optional eye break reminders - Logging users into their EyeCare account - Synchronizing preferences between the EyeCare website and the extension - Improving reliability and user experience EyeCare does not use user data for advertising, tracking, profiling, or selling data to third parties. 4. Local Storage EyeCare Extension stores preferences locally in the browser using Chrome extension storage. Local data may include: - Language preference - Selected filter - Contrast level - Comfort mode setting - Pause reminder setting - Optional login/session token This allows the extension to work even when cloud synchronization is unavailable. Users can clear local extension data by removing the extension or clearing the extension’s stored data through the browser. 5. Cloud Synchronization Cloud synchronization is optional. If you create an EyeCare account and log in, your preferences may be synchronized with the EyeCare backend so that your settings can be shared between the EyeCare website and the EyeCare Extension. To create an EyeCare account, visit: https://eyecare-prci.onrender.com If you do not log in, EyeCare Extension can still work locally without cloud synchronization. 6. Permissions Used by the Extension EyeCare Extension uses the following Chrome permissions: Storage: Used to save user preferences and optional login/session data locally. Notifications: Used only to show optional eye break reminders when the user enables scheduled pause reminders. Alarms: Used to schedule periodic eye break reminders without requiring the popup to remain open. Host permissions / content script access: Used to apply visual filters, contrast adjustment, and comfort mode directly on web pages. This access is used only for visual accessibility features and does not collect or transmit website content. 7. Data Sharing EyeCare does not sell user data. EyeCare may use third-party infrastructure providers only as necessary to operate the service, such as hosting the backend and storing synchronized preferences. User data may be processed by infrastructure services used to provide EyeCare’s core functionality, such as: - Backend hosting - Database storage - Authentication and preference synchronization EyeCare does not share user data with advertisers or data brokers. 8. Limited Use Disclosure EyeCare Extension’s use of user data is limited to providing and improving its single purpose: visual accessibility and comfort tools for web browsing. EyeCare only uses user data to provide user-facing features such as local preferences, login, optional cloud synchronization, visual filters, dynamic contrast, comfort mode, and scheduled eye break reminders. EyeCare does not use user data for unrelated purposes, advertising, tracking, or selling data. 9. Data Retention Local extension data remains stored in the browser until the user changes settings, logs out, clears extension data, or removes the extension. Account and synchronized preference data may be stored while the user maintains an EyeCare account. Users may request deletion of their account data by contacting the developer. 10. Security EyeCare takes reasonable measures to protect user data, including using secure communication with the backend and storing authentication data only for login and synchronization purposes. However, no method of transmission or storage is completely secure, and users should keep their account credentials private. 11. Children’s Privacy EyeCare Extension is not directed specifically to children under 13. The extension is intended as a general visual accessibility and comfort tool. 12. Medical Disclaimer EyeCare Extension is not a medical device and does not diagnose, treat, cure, or prevent any medical condition. The extension provides visual accessibility and comfort tools, but it does not replace professional eye care or medical advice. 13. Changes to This Privacy Policy This Privacy Policy may be updated from time to time. If significant changes are made, the updated version will be posted on the EyeCare website. 14.
